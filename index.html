Coba sendiri

Linear search lawan binary search

Linear: periksa satu per satu. Biner: bagi dua area pencarian (data harus terurut).

Jumlah langkah: 0

Coba angka 97. Bandingkan jumlah langkah linear dan biner.

Kode kedua algoritma

def linear_search(data, target):
    for i in range(len(data)):
        if data[i] == target:
            return i
    return -1
def binary_search(data, target):
    kiri = 0
    kanan = len(data) - 1
    while kiri <= kanan:
        tengah = (kiri + kanan) // 2
        if data[tengah] == target:
            return tengah
        elif data[tengah] < target:
            kiri = tengah + 1
        else:
            kanan = tengah - 1
    return -1

Pengurutan: bubble sort menukar dua elemen bersebelahan yang salah urutan. Selection sort memilih elemen terkecil lalu menaruhnya di depan. Keduanya mudah dipahami, tetapi lambat untuk data besar.

Binary search tidak bisa dipakai pada data yang belum terurut. Linear search tetap berguna untuk data kecil atau acak.
def bubble_sort(a):
    for i in range(len(a)):
        for j in range(len(a) - i - 1):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a

print(bubble_sort([5, 2, 9, 1]))
def selection_sort(a):
    for i in range(len(a)):
        kecil = i
        for j in range(i + 1, len(a)):
            if a[j] < a[kecil]:
                kecil = j
        a[i], a[kecil] = a[kecil], a[i]
    return a

print(selection_sort([5, 2, 9, 1]))
